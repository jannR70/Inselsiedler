# Die Siedler von Catan

Eine digitale Umsetzung des Brettspiel-Klassikers **Die Siedler von Catan**. Baue Siedlungen, handle mit Rohstoffen und werde der unangefochtene Herrscher über die Insel Catan!

2. Laden Sie sich die Datei herunter
